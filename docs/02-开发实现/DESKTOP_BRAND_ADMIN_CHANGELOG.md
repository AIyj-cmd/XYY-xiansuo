# PC 管理后台与品牌数据域变更记录

## 后端

- 新增品牌域持久化模式与版本表。
- 新增品牌、工商主体、分类、网址资源和线索关联 API。
- 新增品牌域 Excel/CSV 导入模板、导入和 Excel 导出。
- 品牌数据域写操作对管理员和业务员开放。
- 线索关系写入继续校验线索负责人。
- 服务启动时初始化品牌域并执行外键检查。

## 前端

- 新增 PC 管理后台壳层、侧边栏、顶栏和桌面内容区。
- 新增桌面工作台。
- 把原有线索列表、详情、跟进、图片、报价、标签、收藏、批量操作、公海和品牌关联迁移到桌面组件。
- 新增品牌列表、筛选、统计、详情抽屉和编辑表单。
- 新增工商主体列表、详情和结构化工商信息表单。
- 新增品牌分类树管理。
- 新增统一导入导出中心。
- 新增桌面用户管理和系统状态页面。
- 登录成功后进入桌面后台。

## 兼容性

- 原线索 API、数据表和移动页面代码保留。
- 不删除 `leads.company_name`。
- 旧版本应用可忽略品牌域新增表。
