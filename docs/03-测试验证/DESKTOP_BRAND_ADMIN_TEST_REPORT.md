# PC 管理后台与品牌数据域测试报告

## 状态

本报告随功能分支提交。合并必须以 GitHub Actions 的实际结果为门禁；不得仅凭页面截图判定通过。

## 自动化覆盖

新增 `server/test/brand-domain.test.ts`，覆盖：

- 品牌域表和外键完整性
- 业务员创建、查看、编辑、删除和恢复品牌
- 工商法人、注册资本、注册地址等字段持久化
- 品牌与工商主体多对多
- 线索与品牌、工商主体多对多
- 业务员不能修改他人线索关系
- 管理员可修改全部线索关系
- 共享网址解除单一品牌关联后不会被误删
- 品牌分类循环层级拒绝
- 品牌列表、汇总和 Excel 导出

## 人工验收清单

1. 管理员登录后进入 PC 工作台。
2. 业务员登录后看不到用户管理菜单。
3. 业务员可以创建、编辑和删除品牌及工商主体。
4. 业务员不能编辑他人负责的线索。
5. 我的线索只展示本人数据；全部线索可以查看公司数据。
6. 新增跟进后，最近跟进和下次跟进按原规则更新。
7. 跟进图片、报价、标签、收藏和批量操作正常。
8. 品牌详情展示工商字段、网址和关联线索。
9. 同一网址关联多个品牌后，解除一个品牌关系不会删除其他关系。
10. 线索品牌关系支持多个品牌和多个工商主体。
11. 品牌导入失败行生成明确行号与原因，成功行保留。
12. 旧线索 Excel 导入权限仍仅管理员可用。
