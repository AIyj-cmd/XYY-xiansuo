# H5-only 前端决策

决策日期：2026-07-30

## 决定

前端交付目标收敛为 H5。之后只构建、发布和验收 H5；微信小程序不再是交付目标。

## 删除与保留

- 删除：`@dcloudio/uni-mp-weixin`、`dev:mp-weixin`、`build:mp-weixin` 和小程序构建/发布验证要求。
- 保留：uni-app 的 H5 依赖、Vite、manifest、pages、App、所有页面与组件、`uni` API、H5 构建产物及业务功能。
- 不为清理修改 manifest，因为其没有专用小程序配置；不触碰泛 `#ifndef H5` 兼容分支。

## 不受影响的“微信”分类

| 分类 | 处理 |
| --- | --- |
| 微信小程序平台依赖、脚本、发布 | 删除或停止使用 |
| 线索微信号字段、跟进方式“微信”、公众号来源 | 保留业务含义 |
| 普通微信/企业微信通知、绑定和渠道安全设计 | 保留为独立未来能力，不随平台清理实现 |
| 历史文档中的小程序构建结果 | 保留为历史事实，并注明已被 H5-only 策略取代 |

本决策不修改 API、数据库、迁移、Worker、Mock、通知基础设施或服务器部署。
